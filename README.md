Teknic Euchner Website

A modern industrial website developed for Teknic Euchner, focused on industrial control gear, sensing, switching, automation, and machine-control solutions.

The website uses a clean industrial design with a dark and white color scheme, red accent colors, large typography, product cards, animated sections, and an automatic image slideshow.

Project Overview

This project is a frontend website created using:

HTML5
CSS3
JavaScript
Google Fonts
HTML5 Video
Intersection Observer API
CSS Animations and Transitions

The website is designed primarily for desktop view.
